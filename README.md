# VoiceCanvas · 语音画板

> 一款面向肢体障碍人士与儿童的纯语音驱动绘图工具——不需要鼠标，不需要键盘，只需开口说话，就能创作属于自己的画作。

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填入 API 密钥

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

├── canvas/
│   └── page.tsx               # 核心画布页面
├── gallery/
