## 0. 本版变更说明（为什么重写）

v1.0 的 PRD 把产品定位为「面向肢体障碍人士的语音画图工具」，并把技术栈写成 Konva.js + Qwen ASR + wanx 文生图。**经过对实际代码的完整盘点，文档与现实存在重大偏差**，本版做了两件事：

1. **诚实校准**：按代码实际能力重写功能边界、技术栈、现状。
2. **商业化转向**：把产品从「无障碍画图工具」重新定位为「**面向 C 端家庭的 AI 语音创作玩具 → 儿童绘本创作**」，这是经过市场判断后、唯一能跑通商业模式的路线（详见 §3）。

> ⚠️ 任何后续文档（TDD / UI_STYLE）都以本 PRD 的现状描述为准，原 v1.0 中与实际代码冲突的部分作废。

## 1. 产品概述

### 1.1 产品名称

**VoiceCanvas**（语音画板）

### 1.2 一句话定位

> 孩子开口说，AI 把他脑海里的画面一笔笔画出来——一个会听话的 AI 画师。

### 1.3 产品本质（现状）

VoiceCanvas 是一个**语音驱动的 AI 场景画板**。它不是传统意义上「说画圆就画圆」的指令绘图工具，而是：

1. 用户用**一句话**描述一个画面（"画一只在樱花树下睡觉的橘猫"）；
2. 后端 LLM 像**画师一样规划场景**：拆解元素、分配颜色/位置/尺寸/图层/光影；
3. 前端 Canvas **逐元素生长式动画**地把整幅画绘制出来，带渐变、阴影、高光、暗角。

这个「**AI 替你把脑中的画面，用几何图形一笔笔拼出来**」的过程感，是产品最核心的体验差异点，也是后续商业化的传播抓手。

## 3. 商业化方向：为什么要转向 C 端儿童创作

### 3.1 为什么放弃「无障碍画图工具」定位

经过商业判断，原定位有三个无法回避的硬伤：

1. **用户群体四散**：肢体障碍者 / 儿童 / 特教 / 创意探索者，是四个完全不同的生意（买单方、渠道、定价都不同）。"四类用户"等于"没有用户"。
2. **没有付费理由**：「语音画几何图形」对任何群体都不构成付费动机——通用 AI 助手免费就能画。
3. **成本不健康**：每条语音 = ASR + LLM 成本，低频小众 C 端订阅无法覆盖。

### 3.2 为什么选 C 端儿童（方向 ②）而非 B 端特教（方向 ①）

| 决策维度 | B 端特教/辅具 | C 端儿童创作 ✅ |
|---------|-------------|--------------|
| 第一笔钱 | 需要 1 所学校试点，周期 3-12 月 | 靠内容获客，1 月内可验证 |
| 团队匹配 | 需资质、教研、政府关系 | 需流量、内容、童趣美术 |
| 技术复用 | 需要重做康复评估体系 | 现有「语音→AI 画师」直接复用 |
| 传播性 | 低（政府采购不传播） | 高（创作过程天然是短视频素材） |

**结论**：主攻 C 端儿童，B 端特教作为未来融资故事（§9）。

### 3.3 C 端儿童方向的核心价值主张

```
孩子开口说 → AI 画师一笔笔把画面拼出来 → 可保存/可分享/可印刷的画作
```

家长付费的不是"工具使用权"，而是三样东西：
1. **产物**：一幅完整的、孩子「亲自创作」的画；
2. **仪式感**：孩子说一句童言童语 → 画慢慢长出来的魔法时刻；
3. **可分享性**：「看我娃用 AI 画的」——朋友圈/小红书社交货币。

## 4. 目标用户（C 端儿童方向）

### 4.1 核心用户

| 角色 | 画像 | 核心诉求 |
|------|------|---------|
| **使用者**：4-9 岁儿童 | 想象力丰富，识字有限，精细动作不稳，喜欢"被看见" | 把脑中的画面变成真的画，像变魔法 |
| **付费者**：25-40 岁妈妈 | 重视教育投入，焦虑屏幕时间，爱晒娃 | 有教育价值的、能晒的、不纯消耗时间的内容 |

### 4.2 用户画像

**画像 A · 小芽（6 岁，大班）**
喜欢编故事，但不会写字也不会画画。对她说"讲讲你的小兔子"，她会蹦出一大段——产品把这些童言变成画面，她会觉得"是我画的"。

**画像 B · 妈妈（32 岁，互联网从业者）**
担心女儿刷短视频，想找"有创造性的屏幕活动"。看到女儿的作品会立刻发小红书，配文"AI 听我娃指挥画画"。

| 能力 | 现状 | 示例 |

### 5.3 商业化功能规划（C 端儿童，按优先级）

#### P0 · 绘本模式（核心付费理由）
> **从"画一幅画"升级为"做一本绘本"**——这是整个商业化的支点。

- 一本绘本 = 封面 + N 页（每页一句话 + 一幅画）
- 支持连续创作：「再讲下一页」
- 导出为可翻页的电子绘本（HTML/PDF）
- **付费点**：免费 3 页带水印，解锁完整本 ¥9.9-19.9

#### P1 · 配音与朗读
- 用 TTS 把孩子每页说的话朗读出来，绘本可"播放"
- 孩子的声音（ASR 录音片段）作为旁白 → 情感价值拉满
- **付费点**：订阅功能

#### P1 · 分享卡片 / 创作过程短视频
- 自动把"语音 + 字幕 + 画面生长动画"剪辑成 15-30s 短视频
- 这是**核心获客通道**——创作过程本身就是营销内容
- 导出竖版（抖音/小红书）和方形（朋友圈）

#### P2 · 童趣风格
- 当前 LLM 生成的几何风偏"设计感"，对儿童偏冷
- 增加"蜡笔/水彩/贴纸"风格的 prompt 模板和渲染参数
- 让画面更像"孩子画的"

#### P2 · 作品云同步与家长后台
- 替换 IndexedDB → 云端存储（Supabase 或自建）
- 家长可查看孩子的创作历史、成长轨迹
- 跨设备同步（手机创作的，iPad 能看）

## 6. 商业模式

### 6.1 收入结构（三段式）

| 层级 | 内容 | 定价 | 目的 |
|------|------|------|------|
| 免费层 | 1 本绘本/永久，3 页以内，带水印 | ¥0 | 裂变获客，降低尝试门槛 |
| 单本购买 | 去水印 + 解锁全部页 + 配音 + PDF 导出 | ¥9.9-19.9/本 | 冲动消费，拉 LTV |
| 月度订阅 | 不限本数 + 私人作品集 + 实体印刷折扣 | ¥29/月 或 ¥258/年 | 沉淀重度用户 |

### 6.2 成本测算（单本绘本）

```
单本假设 = 6 页 = 6 次讯飞 ASR + 6 次 LLM 规划
- 讯飞 ASR：实时听写按时长，约 ¥0.003/15秒 ≈ ¥0.02
- DeepSeek LLM（两步）：约 ¥0.01-0.03/次 × 6 ≈ ¥0.12
单本 AI 成本 ≈ ¥0.15（无文生图，成本极低 ✅）

售价 ¥9.9 → 毛利 ¥9.75（98.5%）
售价 ¥29/月，假设月均 8 本 → 成本 ¥1.2 → 毛利 ¥27.8（96%）
```

> ✅ **关键优势**：当前架构不依赖昂贵的像素级文生图（wanx/Midjourney），用 LLM + 几何渲染，成本结构天然健康。这是相比同类 AI 绘本产品的成本护城河。

### 6.3 冷启动与获客

**核心策略：内容即营销。**

- 把孩子的语音创作过程（童言 + 字幕 + 画面生长）剪成短视频
- 投放抖音/小红书宝妈人群，评论区挂产品
- **每条爆款 = 免费获客通道**
- 孩子的童言童语是天然爆款素材

## 7. 竞品与差异化

| 产品 | 语音创作 | 过程可视化 | 儿童友好 | 成本结构 | 可分享性 |
|------|---------|-----------|---------|---------|---------|
| Midjourney/即梦 | ❌ | ❌（直接出图） | ❌ | 差（文生图贵） | 中 |
| 豆包/通义（通用助手） | 单轮 | ❌ | ❌ | 中 | 低 |
| 各类 AI 绘本 App | ⚠️ 部分 | ❌ | ✅ | 差 | 中 |
| **VoiceCanvas** | ✅ 实时 | ✅ **逐元素生长动画** | ✅ 规划中 | ✅ **最优**（无文生图） | ✅ 规划中 |

**真正的差异化**：
1. **「画师过程」可视化**——AI 一笔笔把画面拼出来的动画，是通用 AI 出图工具没有的体验，天然适合传播；
2. **成本护城河**——LLM + 几何渲染，单次成本 ¥0.02-0.03，碾压文生图方案；
3. **语音原生**——孩子用说的方式创作，契合儿童能力（识字有限）。

## 10. 成功指标

| 维度 | 指标 | 目标 |
|------|------|------|
| 体验 | 语音→首画面延迟 | < 5s（含 LLM 两步规划） |
| 体验 | 缓存命中延迟 | < 500ms（相似指令秒级出图） |
